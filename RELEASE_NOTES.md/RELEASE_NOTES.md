# 轨道塔防 · 发布说明

## v0.1.0（2026-08-10）

### 玩法
- 3D 轨道塔防：敌舰沿轨道进攻基地，建造炮塔防守
- 4 种炮塔：脉冲炮 / 导弹塔 / 光束塔 / 减速塔
- 无限波次，每 5 波一个 Boss，难度持续递增
- 击杀得金币：建塔、升级、出售

### 商业模型
- 免费试玩：阿尔法哨站、贝塔防线（2 张图）
- 完整版 ¥8：爱发电付款 → 游戏内输入订单号自助解锁全部 5 张图
- 付费状态存 localStorage

### 技术栈
- Vite + TypeScript + Three.js
- GitHub Pages 静态部署 + Vercel Serverless 履约层
- Supabase 存储订单 + 爱发电 API 拉模式兜底验证
